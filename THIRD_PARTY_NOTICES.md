# Third-party components used for generated documents

- **Amiri** (`QuranCircles.Web/assets/fonts/Amiri-Regular.ttf`): SIL Open Font License 1.1. The complete license is in `QuranCircles.Web/assets/fonts/OFL-Amiri.txt`.
- **QuestPDF**: The application selects the Community license in `DocumentRenderer`. Confirm the organization meets the current Community eligibility terms before production use; see https://www.questpdf.com/license/.
- **ClosedXML**: Used to create `.xlsx` reports; see its package license at https://www.nuget.org/packages/ClosedXML/.

These packages and the font are not used to store operational data or production credentials.
